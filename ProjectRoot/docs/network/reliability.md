# 신뢰성

## 목적
오프라인/불안정 링크 환경에서도 패킷 전달 성공률과 일관성을 유지합니다.

## 적용 메커니즘
| 항목 | 설정값 | 역할 |
|---|---|---|
| 메시지 TTL | `7 hops` | 전파 범위 제어 |
| 동기화 TTL | `0` | 동기화 패킷 과확산 방지 |
| Dedup 윈도우 | `300000ms` | 중복 패킷 처리 방지 |
| Dedup 최대 이력 | `10000` | 중복 판별 메모리 상한 관리 |
| 조각화 임계치 | `512 bytes` | MTU 초과 시 조각 전송 시작 |
| 최대 fragment 크기 | `469 bytes` | 단편 전송 크기 제한 |
| 재조립 타임아웃 | `30000ms` | 끊긴 조각 세션 정리 |
| ACK 대기 시간 | `5000ms` | 파일 수신 확인 대기 |
| 파일 최대 재시도 | `3` | 실패 전송 복구 |
| 캐시 보관 시간 | `43200000ms` | Store-and-Forward 보관 |
| 캐시 최대 수 | `100` | 캐시 폭주 방지 |
| 캐시 정리 주기 | `600000ms` | 만료 데이터 주기 정리 |

## 기대 효과
- 중복/과전파/단편 손실을 제어해 전달 안정성 유지
- 일시 단절 상황에서도 재전송으로 복구 가능
