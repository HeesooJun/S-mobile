# 근접 센서 (Proximity) - Life Savior

## 목적(왜 쓰나)
- 주머니/가방 상태 감지 → SOS 오작동 방지(잠금/길게누르기)
- 주머니 상태일 때 절전 트리거(지도 갱신, BLE 스캔 주기 낮추기)

## 기기에서 확인한 센서(ADB dumpsys)
- 표준 접근 가능 센서:
  - Palm Proximity Sensor version 2
  - type: android.sensor.proximity(8)
  - perm: n/a  ✅ 일반 앱에서 접근 가능
  - on-change, wakeUp

- 삼성 커스텀 센서(앱에서 접근 어려움):
  - com.samsung.sensor.physical_proximity / touch_proximity 등
  - perm: com.samsung.permission.SSENSOR  ⚠️ 일반 앱 접근 불가 가능성 큼

## 값 특성(동작 방식)
- 대부분 2상태에 가까움
  - near: 0 근처
  - far: maxRange(예: 5.0) 근처
- on-change: 상태가 바뀔 때만 이벤트가 올 수 있음

## 판정 기준(앱 내부)
- proxRaw <= 0.5 → near(true)
- proxRaw > 0.5 → far(false)

## 앱 적용 방식(Kotlin)
- SensorManager.getDefaultSensor(Sensor.TYPE_PROXIMITY)
- SensorEventListener에서 값 수신
- 최신값(lastProxRaw)을 유지해 다른 센서(조도/가속도) 로직과 조합

## Life Savior에서 쓰는 로직 예시
- pocketMode 후보:
  - proxNear == true AND (lux 낮음) 조건과 조합해서 최종 판단

## 로그/데이터 저장
- CSV에 기록 컬럼 예:
  - ts_ms, prox_raw, prox_near, lux, label
