# 2중 트리거 설계 - Life Savior

## 목표
- (조건1) 인터넷 망 끊김 + (조건2) 센서 조건 만족
→ 주변 기기 탐색 → BLE(우선)로 구조요청

## 조건1: 인터넷 끊김
- NetInfo 또는 네이티브 네트워크 체크로
- 끊김이 3~5초 이상 지속될 때만 "오프라인" 확정(일시 끊김 오탐 방지)

## 조건2: 센서 조건
### (A) pocketMode(오작동 방지/절전)
- proxNear + lux 조합
- pocketMode일 때는 자동 SOS를 제한(확인 절차로)

### (B) 사고 후보(가속도 기반 추천)
- shock(충격 spike) + stillness(후속 무움직임) 조합
- shock만으로는 오탐 많음 → 반드시 stillness나 추가 조건 필요

## 트리거 최종 조건(초안)
- offline == true (지속 조건 만족)
AND accidentCandidate == true (충격+무움직임 등)
AND pocketMode == false (자동발동 시)
→ SOS 모드 진입 + BLE 스캔 시작

## 실패 대비
- 조건 만족 시에도 사용자 확인(10초 카운트) 옵션 권장
- false positive 방지
