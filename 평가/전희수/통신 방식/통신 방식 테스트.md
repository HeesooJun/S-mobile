# 통신 방식 공부/테스트 정리

BLE
처음엔 BLE로 시작했다. 구현 난이도가 낮고 바로 테스트가 가능했지만, 거리가 생각보다 짧아서 구조 탐색 범위가 아쉬웠다.

UWB
거리/정확도 문제를 해결하려고 UWB를 찾아봤다. 초광대역이라 정밀 측위에 강하고, 고급 스마트폰에서 지원이 늘고 있다는 걸 알게 됐다. 다만 실제로 테스트 가능한 기기 모델이 한정적이라 당장은 전면 적용이 어려웠다. 그래서 추후 확장 항목으로 남겼다.

BLE Long Range (LE Coded)
응급상황 기준으로는 어차피 최신 폰을 쓴다고 보고, BLE Long Range를 우선순위로 봤다. Bluetooth 5.0부터 추가된 LE Coded PHY를 쓰면 거리 확장이 가능하지만, 대신 데이터 속도(예: 500/125 kbps)는 낮아진다. 구조 신호 정도는 충분히 커버할 수 있다고 판단했다.

Wi-Fi Direct
안정적으로 연결이 가능해지면 Wi-Fi Direct도 후보로 넣었다. AP나 인터넷 없이 기기끼리 바로 연결되는 방식이라 오프라인 상황에 맞고, 대역폭이 넓어서 구조자 쪽에서 데이터(위치/상태)를 더 풍부하게 받을 수 있을 것 같아서 순서상 마지막 단계로 고려했다.
