# SDK 버전 선택 정리

UWB를 핵심 기능으로 쓰는지 확인하면서 SDK 기준을 먼저 정리했다. 결론적으로 최소 버전은 올리고, 최신 권한 정책을 따라가기로 했다.

## 확인한 것

- UWB API는 Android 12(API 31)부터 공식 제공
- Android 13+부터 근거리 통신 권한(NEARBY_WIFI_DEVICES 등)이 강화됨
- 최신 SDK 기준으로 빌드하면 권한/보안 정책 대응이 쉬움

## 결정

- minSdk 31  
  UWB가 핵심이라 API 31을 기준으로 맞췄다.
- targetSdk 34  
  최신 권한 정책을 따라가기 위해 최신으로 설정했다.
- compileSdk 34  
  최신 API 기준으로 빌드해서 호환성 이슈를 줄이려는 목적이다.
