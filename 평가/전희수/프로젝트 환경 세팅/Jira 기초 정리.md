# Jira 처음 써본 느낌

노션에서 이슈 관리를 하다가 Jira를 처음 써봤다. 처음엔 용어가 많아서 좀 어렵게 느껴졌다. 근데 몇 번 만져보니까 “실제로 일을 굴리는” 느낌이 더 강했다.

## 노션이랑 비교해서 느낀 점

노션은 문서 정리에 강하고, 정리해두면 보기 좋다. 근데 이슈 수가 늘어나면 “누가 뭘 하고 있는지”가 금방 흐려졌다. Jira는 이슈 하나 만들면 담당/상태/기한이 바로 붙어서, 진행 상황이 눈에 보여서 편했다.

## Jira가 더 편했던 부분

- 스프린트로 “이번 주 할 일”이 강제로 잘린다.
- 보드에서 상태를 옮기면 팀 전체가 동시에 본다.
- 에픽/스토리/이슈로 잘게 쪼개는 게 자연스럽다.
- 이슈끼리 링크가 되니까 의존성이 잘 보인다.
- 보고서나 통계가 자동으로 나온다.

## 아직 익숙하지 않은 부분

- 처음 세팅할 때 워크플로우/권한이 헷갈렸다.
- 필드가 많아서 “뭘 적어야 하는지” 고민된다.
- 템플릿을 잘 만들기 전까진 조금 번거롭다.

## 결론

노션은 정리용으로 좋고, Jira는 실행용으로 더 편했다. 특히 팀 단위로 “지금 뭘 하고 있는지”를 빠르게 공유할 때는 Jira가 훨씬 직관적이었다.
