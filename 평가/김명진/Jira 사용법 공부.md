# Jira 사용법 공부

## 1. 에픽, 스토리, 태스크 구분하기

Jira는 작업을 크기별로 계층적으로 관리한다.

*   **에픽 (Epic)**
    *   **개념**: 큰 규모의 작업 덩어리. 하나의 큰 기능이나 장기 목표.
    *   **예시**: "회원 시스템 개발", "검색 기능 도입"
    *   **특징**: 보통 여러 스토리로 나눠서 진행한다.

*   **스토리 (Story)**
    *   **개념**: 사용자에게 가치를 주는 기능. 에픽을 잘게 나눈 것.
    *   **예시**: "이메일/비밀번호로 로그인하기", "아이디 찾기"
    *   **특징**: 보통 하나의 스프린트 안에서 끝낼 수 있는 크기.

*   **태스크 (Task)**
    *   **개념**: 스토리를 완료하기 위해 해야 할 구체적인 개발 업무.
    *   **예시**: "로그인 API 만들기", "로그인 페이지 UI 그리기", "로그인 기능 테스트 코드 작성"
    *   **특징**: 개발자 한 명이 며칠 안에 처리할 수 있는 작은 단위.

## 2. 이슈 상태 바꾸기 (To Do / In Progress / Done)

Jira 보드에서 작업의 진행 상황을 나타내는 기본적인 상태들.

*   **할 일 (To Do)**
    *   **설명**: 아직 시작 안 한 작업들이 있는 곳.
    *   **전환**: 일을 시작하면 `진행 중`으로 옮긴다.

*   **진행 중 (In Progress)**
    *   **설명**: 지금 하고 있는 작업.
    *   **전환**: 일이 끝나면 `완료`로 옮긴다.

*   **완료 (Done)**
    *   **설명**: 끝난 작업. 요구사항에 맞게 개발되고 테스트까지 완료된 상태.

## 3. 이슈 만들고 상태 바꾸는 법

### 이슈 만들기

1.  Jira에서 '만들기(Create)' 버튼 클릭.
2.  `이슈 유형` 선택 (에픽, 스토리, 태스크 중 하나).
3.  `요약`에 제목 쓰기.
4.  `설명`에 상세 내용 적기.
5.  `담당자` 지정.
6.  `연결` 기능을 사용해서 에픽-스토리-태스크를 서로 연결해주면 구조 파악이 편하다.
7.  필요한 정보 입력 후 '만들기' 클릭.

### 상태 바꾸기

1.  **상세 화면에서 바꾸기**:
    *   이슈를 클릭해서 상세 내용을 본다.
    *   상태(Status) 버튼을 눌러서 `진행 중` 또는 `완료` 등으로 변경한다.

2.  **보드에서 드래그 앤 드롭**:
    *   칸반 보드나 스크럼 보드에서 카드를 마우스로 끌어서 `할 일` -> `진행 중` -> `완료` 컬럼으로 옮긴다. 이게 제일 편하고 직관적이다.
