# LTE 없는 환경에서의 모바일 오프그리드 통신

## P2P 기반 통신 및 위치 기술 검토 (Mesh는 차후 목표)

## 1. 개요 (Context)

본 프로젝트의 **1차 목표는 LTE/5G가 전혀 없는 오프라인 환경에서 스마트폰
간 P2P(Point-to-Point) 통신을 구현**하는 것입니다.\
텍스트(채팅), 음성(보이스), 그리고 **상대방의 위치(거리/방향)**를
파악하는 것이 핵심 기능입니다.

> **Mesh 네트워크는 초기 목표가 아니며**,\
> P2P 통신이 충분히 안정화된 이후 **확장 목표(Phase 2)**로 고려합니다.

------------------------------------------------------------------------

## 2. 통신 기술 검토 (Communication: Chat & Voice)

### ✅ BLE Long Range (LE Coded PHY)

**P2P 텍스트 통신 및 위치 데이터 교환의 핵심 기술**

-   **채팅(Text)**\
    패킷 크기가 작아 125kbps 속도로도 수백 미터 거리에서 안정적인 P2P
    통신 가능.
-   **음성(Voice)**\
    일반적인 음성 코덱(Opus 등)을 사용하기에는 대역폭과 레이턴시 한계가
    큼.\
    무전기 수준의 저품질 PTT 음성도 현실적으로는 품질 보장 어려움.
-   **거리**\
    숲/도심 환경에서도 수백 미터 이상 도달 가능.
-   **평가**\
    저전력, 장거리 특성으로 **초기 P2P 구현에 가장 현실적인 선택**.

> Mesh 확장은 가능하나, 본 문서에서는 **P2P 사용을 전제로 기술**합니다.

------------------------------------------------------------------------

### ⚠️ Wi-Fi Direct / Wi-Fi Aware

**음성 통신을 위한 선택적 P2P 고대역폭 채널**

-   **음성(Voice)**\
    실시간 음성 통신 또는 고음질 음성 메시지 전송 가능.
-   **배터리 소모**\
    상시 사용은 현실적으로 불가.
-   **전략**
    -   기본 상태: BLE P2P 대기\
    -   음성 필요 시: 상대 기기와 Wi-Fi Direct P2P 연결

------------------------------------------------------------------------

## 3. 위치 및 방향 탐지 기술 검토 (Location & Direction)

### 📍 A. GPS 기반 방향 탐지 (중·장거리)

-   **방식**\
    각 기기가 자신의 GPS 좌표(위도/경도)를 BLE P2P로 교환.
-   **계산**
    -   Haversine 공식: 거리 계산\
    -   Bearing 계산: 내 기준 상대 방향 산출
-   **출력 예시**\
    `북서쪽 약 320m`
-   **장점**\
    수 km 거리에서도 정확, 추가 하드웨어 불필요.
-   **한계**\
    실내, GPS 음영 지역에서는 사용 불가.

------------------------------------------------------------------------

### 🎯 B. UWB 기반 정밀 탐지 (근거리)

-   **방식**\
    전파 도달 시간(ToF)을 이용한 직접 거리 측정.
-   **성능**
    -   거리: cm 단위 정확도\
    -   방향: 기기 회전에 따른 상대 위치 방향 탐지
-   **활용 시점**\
    GPS가 불안정하거나 **근거리(약 50m 이내)에서의 탐색 보조 수단**
-   **제약**\
    UWB 지원 기기 필요 (iPhone 11+, Galaxy S21+ 등).

> 본 프로젝트에서는 **AR 시각화는 구현 대상에서 제외**하며,\
> 방향 정보는 화살표/각도 수치 등 **단순 UI**로 표현합니다.

------------------------------------------------------------------------

### ❓ C. BLE RSSI

-   **거리 추정**\
    신호 세기 기반으로 오차가 매우 큼.
-   **방향 탐지**\
    일반 스마트폰에서는 불가.
-   **활용**\
    보조 지표 또는 근접 여부 판단용.

------------------------------------------------------------------------

## 4. 기술 조합 요약 (P2P 기준)

  구분   목적                  추천 기술        비고
  ------ --------------------- ---------------- ------------------
  통신   텍스트 채팅           BLE Long Range   기본 P2P 통신
  통신   음성 통화             Wi-Fi Direct     필요 시에만 사용
  위치   중·장거리 방향/거리   GPS 좌표 교환    BLE P2P

## 5. 개발 로드맵 (Action Plan)

### Phase 1. P2P 기본 기능 (현재 목표)

-   BLE Long Range 기반 **1:1 텍스트 채팅**
-   GPS 좌표 교환
-   상대방 **방향/거리 표시 UI (나침반/각도 기반)**

### Phase 2. P2P 음성 확장

-   음성 버튼 트리거
-   Wi-Fi Direct 기반 PTT(Push-To-Talk) 또는 음성 통화

### Phase 3. 근거리 탐색 보강

-   GPS 또는 RSSI 기반 근접 판단
-   UWB 활성화 안내
-   단순 화살표/방향 수치 UI 제공

### Phase 4. Mesh 네트워크 (장기 목표)

-   다수 노드 간 메시지 릴레이
-   위치 정보 다중 전파
-   배터리/토폴로지 관리 연구

------------------------------------------------------------------------

## 참고

본 문서는 재난·조난·오프그리드 환경에서의 **모바일 P2P 통신 시스템**을
1차 목표로 하며, Mesh 네트워크는 **추후 확장 가능성**으로 남겨두었습니다.

### BLE 테스트 결과 요약
- **BLE_Test 0.0.1**: BLE Long Range를 이용하여 1:1 채팅 및 저품질 음성(PTT) 기능의 구현 가능성을 테스트했습니다. 대역폭을 512까지 증폭하여 테스트한 결과, 텍스트는 50m 이상, 음성은 30m~40m까지 전달이 가능했습니다.
- **BLE_Test 0.0.2**: 두 기기의 상대적 거리를 측정하는 기능을 테스트했습니다. 이 과정에서 채팅 및 음성 기능에서 버그가 발생하여 안정적인 통신에 어려움이 있었습니다.
