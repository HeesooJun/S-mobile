# BLE 및 UWB 기술 

## 1. BLE (Bluetooth Low Energy)
최소한의 전력으로, 소량의 데이터를, 장기간 전송하는 기술

1) 개념
- 기존 블루투스(Classic)의 높은 전력 소모 문제를 해결하기 위해 설계됨
- 배터리 하나로 수년 간 작동 가능한 초저전력 효율성이 핵심임
- 느리지만 꾸준히 데이터를 나르는 '거북이 우편 배달부'에 비유됨
2) 구현 원리
- 듀티 사이클링 (Duty Cycling): 대부분의 시간 동안 수면(Sleep) 상태를 유지하다가, 데이터 전송 시에만 아주 짧게 깨어나 활동함
- 주파수 호핑 (Frequency Hopping): 2.4GHz 대역을 40개 채널로 나누고 빠르게 이동하며 전파 간섭을 회피함
- GATT 프로파일: 미리 정의된 규격(Profile)을 사용하여 데이터 처리 부하를 최소화함.
3) 역사
- 2001년: 노키아(Nokia)가 'Wibree'라는 명칭으로 개발함.2010년: 블루투스 4.0 표준에 통합되며 'Bluetooth Low Energy'로 명명됨
- 현재: Bluetooth 5.0 이상으로 발전하며 전송 거리와 속도가 대폭 개선됨
4) 활용 분야
- 웨어러블: 스마트워치, 밴드 등 모바일 기기와의 상시 연결
- 헬스케어: 연속 혈당 측정기(CGM), 심박계 등 소량 데이터 전송
- 비콘(Beacon): 실내 위치 기반 마케팅 및 O2O 서비스
- IoT 센서: 스마트 홈 온도/습도 센서 등

## 2. UWB (Ultra-Wideband)
광대역 주파수를 활용한 cm 단위의 초정밀 측위 기술
1) 개념500MHz 이상의 매우 넓은 주파수 대역폭을 사용하는 통신 기술임.데이터 전송보다는 정밀한 거리 측정과 방향 인식에 특화됨. 매우 빠르고 정확한 '레이저 거리 측정기'에 비유됨
2) 구현 원리
- 임펄스 방식 (Impulse Radio): 연속적인 파동(Sine wave)이 아닌, 매우 짧은 나노초(ns) 단위의 펄스를 발사함
- ToF (Time of Flight): 전파가 대상에 도달하고 돌아오는 시간을 측정하여 거리를 계산함.$$거리(d) = 빛의 속도(c) \times 시간(t)$$
- AoA (Angle of Arrival): 수신 안테나 간의 위상차를 이용해 신호가 들어오는 각도(방향)를 산출함
3) 역사
- 초기: 1900년대 초반 무선 통신의 시초 기술이었으나, 간섭 문제로 사장됨
- 중기: 1960~90년대 군사용 레이더 및 보안 통신용으로 제한적 사용됨
- 확산: 2019년 애플(Apple)이 아이폰 11에 U1 칩을 탑재하고, 삼성/BMW 등이 참여하며 상용화가 가속됨

4) 활용 분야
- 디지털 키: 스마트폰 소지 후 차량 접근 시, cm 단위 거리 인식으로 문을 자동 개폐함. (릴레이 해킹 방지)
- 분실물 추적: 에어태그(AirTag), 스마트태그 등 물건의 정확한 위치와 방향 탐색
- 공간 인식 공유: 에어드랍(AirDrop) 시 기기를 가리키는 방향에 있는 사용자를 우선 인식함.

## 3. 기술 비교 요약
| 구분 | BLE (Bluetooth LE) | UWB (Ultra-Wideband) |
| :--- | :--- | :--- |
| **핵심 가치** | 저전력 연결, 보편성 | 초정밀 위치 측위, 보안성 |
| **측위 방식** | 신호 세기 (RSSI) 기반 | 도달 시간 (ToF) 기반 |
| **위치 정확도** | 미터(m) 단위 (오차 큼) | 센티미터(cm) 단위 (오차 작음) |
| **보안 수준** | 중간 (해킹 위험 존재) | 매우 높음 (물리적 거리 검증 가능) |
| **전력 소모** | 매우 낮음 (코인 배터리 수년) | BLE 대비 높음 (필요 시 작동) |
| **주요 용도** | IoT 센서, 웨어러블, 비콘 | 디지털 키, 정밀 위치 추적 |
## 4. 융합 활용 (Hybrid Scenario)
최신 서비스(예: 디지털 차 키)에서는 두 기술을 상호 보완적으로 사용함
- 감지 (BLE): 원거리에서 저전력으로 사용자 접근을 감지하고 연결함("Wake-up" 역할)
- 측위 (UWB): 연결 후 UWB를 활성화하여 정밀 거리를 측정하고, 특정 거리(예: 50cm) 도달 시 잠금을 해제함
- 결론: BLE는 **'연결의 지속성'**을, UWB는 **'위치의 정확성'**을 담당하는 형태로 발전 중임
