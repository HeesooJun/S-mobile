# TTS와 STT

단순히 데이터의 형태를 바꾸는 것이 아니라는 점
- 방대한 음성 데이터를 학습하여 사투리나 부정확한 발음에도 문맥상 가장 확률이 높은 단어를 찾아냄
- 자연어 처리 NLP 기술과 결합된 AI & 노이즈 처리 학습
- 딥러닝. 사람이 말하는 것처럼 표현
- 텍스트를 통째로 입력받아 문장의 분위기, 쉼표의 길이, 운율 등 스스로 결정하고 생성
- 목소리 복제

데이터 학습을 통한 패턴 인식 및 생성

## TTS
Text To Speech

Text 형태의 데이터를 음성으로 변환하는 기술

### 작동 원리
1. 언어 분석
- 단어의 발음, 문법 구조, 문맥 파악
- 어떻게 읽을지 결정
2. 음성 합성
- 딥러닝, 신경망 기반 구조
- 자연스러운 음성 생성


텍스트 -> Mel-Spectrogram -> 출력

Mel-Spectrogram: 텍스트를 소리의 주파수 패턴을 나타내는 이미지

AI는 글자 입력 시 주파수 그림이 대응되는 함수 관계를 학습

### 학습 과정
목표: AI가 그린 스펙트로그램과 실제 성우의 스펙트로그램의 Loss를 0으로 줄이기

데이터셋: 텍스트와 음성 파일 쌍

STFT: 시간 도메인의 소리 파형을 주파수 도메인으로 변환해서 모델에 넣어줌

### 활용
- 화면 낭독 프로그램
- 점자 디스플레이
- 내비게이션, 교육 이러닝 등


## STT
Speech To Text

음성을 텍스트로 변환 및 출력하는 기술

### 작동 원리
1. 오디오 신호 수집
2. 전처리 
3. 음향 모델 적용
- 음성 주파수 분석. 단어 구분, 음성 패턴 학습
4. 언어 모델 적용
- 문법 및 문맥 분석, 정확한 문장 구성
5. 텍스트 출력 및 보정
### 학습 과정
TTS의 역함수

연속적인 소리 파형을 이산적인 텍스트 데이터로 매핑하는 확률 과정

CTC Loss (Connectionist Temporal Classification)

Transformer(Attention) 모델
- 소리 전체 다 듣고, 텍스트 전체를 한 번에 생성하는 Whisper 방식

### 활용
- 음성 비서
- 자동 자막 생성
- 회의록 작성
