# 협업 툴

## 노션
프로젝트 스펙, 회의록, 온보딩 가이드, 팀 규칙 등 기록

- 홈: 대시 보드 형태로 Jira, Figma 등 링크
- 설계, 리소스, 개발 대시보드
- 프로젝트 진행 일정 캘린더

## Jira
개발 Task 관리, 일정 산정, 버그 리포팅 등
- 계층 구조
    - 에픽(Epic): 가장 큰 목표 / 프로젝트. "결제 시스템 구축"
    - 스토리(User Story): 사용자 관점 기능 요구사항. "사용자는 카톡으로 간편 로그인 할 수 있다."
    - 태스크(Task): 개발자 관점에서 할 기술적 작업. "결제 DB 스키마 설계"
    - 서브 태스크(Sub-tast): 실무자 실제 작업 체크리스트. 로그인 스토리 하위에 Sub 로그인 API 구현 등

- 스프린트(Sprint) 운영
    - 백로그: 앞으로 해야 할 모든 일(Story,Task)를 쌓아두는 창고. 우선순위대로 정렬
    - 스프린트 계획: 백로그에서 이번 주에 처리할 티켓만 "활성 스프린트"로 옮김
        - 스토리 포인트: 각 티켓의 난이도를 숫자로 매김
    - 칸반 보드: Todo -> In Progress -> Done 으로 옮기며 진행상황 시각화

## Figma
UI 디자인, 프로토타이핑, 개발자에게 가이드 전달

- FigJam: 온라인 화이트보드
    - 본격 디자인 전 기획자와 개발자가 낙서하듯 논의
    - User Flow 화면 순서도 그리기
    - 브레인 스토밍
    - 정보 구조도
    - 여기서 확정된 내용 복사하여 Figma Design 파일로 가져감

- Figma Design: 실제 UI 디자인 & 프로토 타이핑
    - 픽셀 단위로 화면을 그리는 곳
    - 오토 레이아웃
    - 컴포넌트 & 배리언트
    - 프로토타입

- Dev Mode (개발자 모드): 개발자를 위한 전용 뷰
    - 인스펙트
    - 치수 확인
    - 에셋 다운로드
    
## 깃랩
소스 코드 저장, 코드 리뷰, CI/CD
- 브랜치 전략(Git Flow)
- 커밋 메시지 컨벤션
- Merge Request 규칙


# IDE
통합 개발 환경

개발 생산성을 높이기 위해 여러 개발 도구를 하나의 GUI 프로그램으로 통합한 소프트웨어 패키지

소스 코드 편집기 + 빌드 자동화 도구 + 디버거

- 예시: 안드로이드 스튜디오, vscode, IntelliJ

- 안드로이드 스튜디오 (IDE)
    - Gradle (빌드 툴) 내장
    - Logcat과 디버거를 통해 런타임 환경을 제어할 수 있음

# Framework
소프트웨어 구조 결정하는 코드 집합

- 표준화된 설계 패턴(MVC, MVVM 등) 제공

소프트웨어의 구체적인 기능 구현을 위해 제공되는 재사용 가능한 클래스와 라이브러리의 집합체이자 아키텍처를 강제하는 반제품 소프트웨어
