# 시연 시나리오(참고)

## 인력
- 카메라맨
- 구조자
- 생존자1
- 생존자2

## 시작 위치
- 구조자: 202호 앞 복도
- 생존자1: 202호 교실 맨 앞(스크린 아래)
- 생존자2: 소회의실
- 카메라맨: 생존자1 화면 촬영

## 준비물
- 구조자 바디캠(휴대폰)
- 구조자 휴대폰
- 생존자1 휴대폰
- 생존자2 휴대폰

## 사전 준비
- UWB 연결 위치 설정
- 시나리오 리허설
- 바디캠 외 휴대폰 OBS 마이크 OFF
- 생존자 단말 벨/알림 소리 최대

## 캠 시나리오
| 장면/보여줄 화면 | 카메라맨 | 구조자 바디캠 |
| --- | --- | --- |
| #1 202호 | 생존자1 충격 감지/앱 실행, 구조 신호 송출 | 구조 신호 수신 |
| #2 복도 | 구조자 이동, 소회의실로 이동 | 생존자2 위치 화면 |
| #3 소회의실 | 구조자 접근, 반응(소리/채팅/STT) | 1:1 연결/통화, 현장 도착 |

## 대본

### 강의실 202호 (지진 상황)
사람1: (불이 깜빡이며) 지진이야! 지진!
[ 사람1은 문을 열며 대피 ]

[ OBS 화면 전환 / PPT는 기술 소개 슬라이드로 이동 ]

생존자1: (놀라며) 어?! 지진이야!!
[ 뒤에 있던 가구가 생존자를 덮침 ]

생존자1: 으아아아아아!!
[ 자동 신고 미작동 시 SOS 버튼 클릭 ]
생존자1: 살려줘...

### 복도
구조자: 괜찮으세요?

사람1: 저는 괜찮습니다. 하지만 강의실 안에 대피하지 못한 사람이 있던 것 같습니다!
[ 구조자는 202호 방향으로 이동 ]

구조자: 혹시 모르니 구조 요청이 있는지 먼저 확인해보겠습니다.
구조자: 현재 인터넷망이 끊겨 통신이 되지 않는 상황입니다.
구조자: BLE MESH 망에 접속해 생존자가 있는지 확인하겠습니다. (SOS 버튼)

[ 통화 연결이 가능한 호실까지 이동 ]
[ BLE MESH 망 연결 ]

구조자: 방금 BLE MESH 망에 연결되었습니다.
구조자: 상황실에서 생존자 요청을 확인했습니다. 우선 채팅을 보내겠습니다.
[ 채팅 발송 후 통화 가능한 위치로 이동 ]

구조자: 채팅 응답이 없어 통화를 시도하겠습니다.
[ 통화 연결 ]

구조자: 들리십니까? 구조 대원입니다!
생존자1: 들립니다!

구조자: 괜찮으십니까? 지금 상태가 어떻습니까?
생존자1: 다리가 깔려서 움직이질 못하겠습니다. 피가 나는 것 같습니다.

구조자: 금방 가겠습니다. 지금 계신 곳이 202호 맞습니까?
생존자1: 네 맞습니다.
구조자: 알겠습니다. 지금 거의 도착했습니다.
