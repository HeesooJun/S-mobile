# 4. 시연 시나리오

## 실제 시연(교육장) 기준
- 실제 시연은 [시연 시나리오(참고).md](시연%20시나리오(참고).md)를 기반으로 진행했습니다.
- 교육장 환경 제약으로 일부 기능/장면은 축약하거나 제외했습니다.

## 시나리오 개요
실제 붕괴 현장을 가정한 대본형 시나리오입니다. 기능 하나마다 의미를 부여해 자연스럽게 이어지도록 구성했습니다.

## 등장 인물
- 생존자 A (중상, 움직임 제한)
- 생존자 B (경상, 의식 O)
- 생존자 C (의식 저하/응답 지연)
- 구조자
- 주변 단말(중계 노드)

## 시나리오 (대본)

1. 장면 1 — 통신 두절 감지 시작
설명: 현장 전원 차단과 통신 두절로 인터넷/셀룰러 모두 끊김. 앱은 통신 고립을 감지하고 음성 감지 대기 상태로 전환.
화면: “통신 두절! 구조 요청을 듣고 있습니다.”

2. 장면 2 — 생존자 A: 충격 감지 → 구조 요청
설명: 낙상/충격 감지 후 경보 팝업이 뜨고 즉시 구조 요청을 누름.
대사: 생존자 A: “넘어졌어요… 움직이기 힘들어요.”
화면: “🚨 비상 상황 감지! … 구조 요청” → 확인
동작: SOS 송출 시작, “초절전 모드로 신호 전송 중 / 화면 밝기 최소화” 상태로 전환.

3. 장면 3 — 생존자 B: 음성 트리거 → 구조 요청
설명: 음성 감지가 “구해줘/구조 요청” 문장을 인식해 구조 모드로 진입.
대사: 생존자 B: “구해주세요!”
화면: “🚨 비상 상황 감지! … 구조 모드로 전환합니다.”
동작: 구조 요청 송출 시작.

4. 장면 4 — 생존자 C: 무응답 타이머 자동 송출
설명: 의식 저하로 반응이 없어 30초 무응답 타이머가 자동으로 구조 신호 송출.
화면: “⏱️ 시간 초과로 자동 송출”

5. 장면 5 — 생존자끼리 메쉬망 형성 + 대화 시작
설명: A, B, C 단말이 서로 중계 노드로 참여해 메쉬망이 자동 형성됨.
대사: 생존자 B(채팅): “다들 들려요? 저는 복도 쪽에 있어요.”
대사: 생존자 A(채팅): “202호 앞… 다리가 움직이지 않아요.”
대사: 생존자 C(채팅, 지연 수신): “소회의실… 숨이 차요.”
의미: 구조자가 도착하기 전에도 생존자 간 위치/상태 공유가 가능함.

6. 장면 6 — 프로필/특이사항 공유
설명: 각 생존자는 프로필에 이름/생년월일/성별/특이사항을 입력해 구조자에게 전달됨.
대사: 생존자 B(채팅): “천식 있어요. 흡입기 필요합니다.”
의미: 구조자는 생존자 목록에서 특이사항을 확인해 우선순위를 조정.

7. 장면 7 — 구조자 도착: 구조 신호 탐색 시작
설명: 구조자가 앱 실행 후 SOS 탐색 버튼을 눌러 주변 신호 스캔.
화면: “구조 신호 탐색 중 / 주변 기기의 SOS 신호를 스캔하고 있습니다 / 인근 SOS 수신 시 자동 연결됩니다”
동작: 생존자 목록 자동 갱신.

8. 장면 8 — 생존자 네트워크 지도 확인
설명: 구조자가 ‘생존자 네트워크’ 지도를 열어 메쉬 연결 상태를 시각적으로 확인.
의미: 끊긴 구역/약한 연결을 파악해 접근 동선을 결정.

9. 장면 9 — 거리 추정으로 접근 경로 결정
설명: UWB 지원 시 UWB 거리, 미지원 시 BLE RSSI 거리로 대체.
대사: 구조자: “가장 가까운 A부터 접근합니다.”
동작: 거리 피드백을 ‘진동+소리’ 모드로 설정해 접근 중 체감 가능.

10. 장면 10 — 전체 채팅으로 상황 통제
대사: 구조자(전체 채팅): “구조대입니다. 가능한 분은 위치와 상태를 알려주세요.”
대사: 생존자 B: “복도 끝, 유리 파편 많습니다.”
대사: 생존자 C: “소회의실 안, 움직이기 어렵습니다.”
의미: 다중 대상 동시 대응(브로드캐스트 메시지).

11. 장면 11 — 음성 메시지(PTT)로 응급 지시
설명: 통화가 불안정할 때 음성 메시지를 녹음해 전송.
대사: 구조자(PTT): “움직이지 말고, 소리 들리면 대답하세요.”
동작: 음성 메시지는 [voice] 형태로 채팅에 저장·공유됨.

12. 장면 12 — 통화 연결 (가까이 접근 후)
설명: 충분히 근접하면 통화 연결이 성립.
화면: “통화 연결 대기 중… → 통화 연결됨”
대사: 구조자: “들리십니까? 구조 대원입니다.”
대사: 생존자 A: “네… 다리가 깔렸어요.”
의미: 직접 대화로 상태 확인 및 구조 안내.

13. 장면 13 — 원격 제어로 위치 유도
설명: 먼지/시야 불량으로 위치 확인이 어려워 원격 제어 사용.
동작: 구조자 → ‘비프음’ 송출
대사: 구조자: “소리 들리는 방향으로 손을 흔들어 주세요.”
동작: ‘저주파(진동)’ 송출로 손에 쥔 단말 반응 유도
동작: ‘고주파’ 송출로 소음 환경/탐색견·장비 탐지에 유리한 신호 제공
의미: 환경에 맞는 다양한 신호로 위치를 확정.

14. 장면 14 — 경보 중지 + 절전 모드 제어
설명: 위치 확인 후 소음/혼란 방지를 위해 경보를 중지.
동작: ‘경보 중지(STOP_ALERTS)’ 실행
설명: 구조 대기 대상은 배터리 보존을 위해 원격 ‘절전 켜기’, 접근 시 ‘절전 해제’ 또는 ‘화면 켜기’로 복귀.
화면: “구조자 요청: 절전 모드 켜기/해제”
의미: 장시간 구조 상황에서 배터리 생존성 확보.

15. 장면 15 — 누락 동기화로 메시지 복구
설명: 릴레이 단절로 일부 메시지가 누락되었다가, 새로운 중계 노드 합류 시 동기화 요청으로 복구됨.
의미: 끊긴 구역을 지나도 기록과 상태가 뒤늦게 정확히 맞춰짐.

16. 장면 16 — 구조 완료 및 종료
대사: 구조자(전체 채팅): “A 구조 완료. 다음 대상 접근합니다.”
설명: 구조 완료 처리 후 안전 연결 해제.
동작: “연결 해제”를 눌러 종료, SOS 송출 중단 및 네트워크 이탈 처리.
